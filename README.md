# Pondo ng Bayan, Para sa Bayan

A standalone, responsive website presentation adapted from the project owner’s 11-slide Canva advocacy proposal. This project is independent of the SAS2000 student portal.

## Run
Open `index.html` directly in a modern browser. No dependencies, installation, or build step. All CSS, JavaScript, and supplied photographs are embedded in this single file.

## Present
Use the chapter menu, progress markers, arrow buttons, left/right keys, Home/End, or horizontal swipes. Fullscreen is available on supporting browsers. “Read all chapters” provides a continuous reading view. The About dialog includes source context and print/PDF access. Reduced-motion preferences are respected.

## Content
Source: https://www.canva.com/design/DAHYohnKyPg/LvWkhMA0JlhDK_hybZAS0A/edit
The source is a student advocacy proposal, not an independently verified investigative report. Allegations remain qualified; campaign metrics are planned indicators rather than claimed results. The Facebook page name Baha-Bahagi is shown without an unverified destination link. All four images were provided by the project owner; the budget graphic is available as contextual supplied media in About and is not used as evidence.

## Deploy
Static site on Vercel: framework Other, no build command, output directory `.`. `vercel.json` records these settings. Repository and deployment are separate from SAS2000.
